# GameBox

GameBox is a Django-based web platform where users can browse, upload, and discuss video games. The project includes features such as user registration, game listings with detailed descriptions, screenshots, comments, and a REST API with CRUD operations.

## Features

- User authentication (registration, login, logout, profile update)
- Browse a list of games with search functionality
- View game details, screenshots, and system requirements
- Leave comments on games
- REST API for games, screenshots, and comments
- Admin panel for managing games and users

## Tech Stack

- Python 3.11
- Django
- Django REST Framework (DRF)
- PostgreSQL
- HTML/CSS templates
- DRF-YASG (Swagger) for API documentation
